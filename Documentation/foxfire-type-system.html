Rules

Tiers mirror the Color System. Volunteers get Figtree alone, all weights, the way they get the Working Set. The three-face system is the website's and yours.

Size floors. Rosarivo ≥28px, ≥32px reversed. Crimson Text ≥19px, and only in long-form contexts. Figtree has no floor above 12px.

Ink rules bind harder on thin type. Crimson sets in Nightfall only. Figtree may use Twilight 1–2 for secondary text and captions. Rosarivo may take the Color System's display inks... Nocturnal 1–3, Moonrise 1–2, Golden Hour 1–2... because it only exists at display sizes where they pass.

Two serifs, two voices. Rosarivo speaks as Foxfire: headlines only. Crimson Text quotes people: pull quotes 24–28px italic with the hanging mark in a display ink, block quotes 19px roman with a Twilight 4 rule, attributions in Figtree. Always Nightfall ink, and the floors still apply... a quote is never an excuse for small Crimson.

No near-duty for the wordmark pair. The licensed faces never set headings, quotes, or documents. Rosarivo flanks the wordmark's register without imitating it; if a layout ever makes them read as the same voice, the heading demotes to Figtree 700.

Fallback stacks. Rosarivo → Georgia, serif · Crimson Text → Georgia, serif · Figtree → system-ui, sans-serif.

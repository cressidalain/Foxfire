Formats & hygiene

Masters: SVG with all type outlined, per the licensing ruling. Exports: PNG at listed sizes, transparent except the self-grounded coin and glyph. File naming carries asset · state · size (e.g. foxfire-primary-stacked-D.svg, foxfire-coin-512.png) so the folder governs itself. Every file traces to exactly one manifest row.
